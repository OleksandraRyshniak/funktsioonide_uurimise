# Funktsioonide uurimine

Veebirakendus matemaatiliste funktsioonide uurimiseks. Kasutaja saab sisestada funktsiooni ning valida, milliseid omadusi soovib arvutada.

## Funktsionaalsus

Rakendus võimaldab:

- leida määramis- ja muutumispiirkonna;
- arvutada tuletise ja nullkohad;
- leida kasvamis- ja kahanemispiirkonnad;
- leida ekstreemumid ja käänupunktid;
- määrata funktsiooni positiivsus- ja negatiivsuspiirkonnad;
- kuvada funktsiooni graafiku;
- salvestada ja vaadata varasemaid uuringuid;
- muuta ja kustutada salvestatud uuringuid.

Rakenduses on ka **Teatmik**, kus saab vaadata funktsioonide uurimisega seotud informatsiooni.

## Tehnoloogiad

- C#
- ASP.NET Core MVC
- .NET 10
- Entity Framework Core
- SQLite
- Razor Views
- JavaScript
- MathNet.Symbolics
- NCalc
